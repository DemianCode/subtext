How to Install Subtext in Google Chrome
1
Download & Extract Package:
Download the extension ZIP file and extract the folder to your computer.
2
Open Chrome Extensions:
Navigate to chrome://extensions in Chrome and turn ON Developer mode in the top-right corner.
3
Load Unpacked Extension:
Click Load unpacked and select the extracted extension folder. You're all set!
